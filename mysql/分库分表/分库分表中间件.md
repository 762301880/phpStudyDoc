## ShardingSphere-Proxy(待补充)

> ShardingSphere-Proxy 是一个数据库代理，服务端程序，支持 MySQL/PostgreSQL 协议；客户端可以直接用 MySQL 连接工具连接，无需改业务代码，适合做分库分表、读写分离。 环境：Linux（CentOS / Ubuntu），JDK8+，MySQL 版本：5.4.1（稳定版，推荐）

**中文文档**

[shardingsphere中文文档地址](https://shardingsphere.apache.org/document/current/cn/overview/)

###  准备环境

JDK 8 及以上

```bash
java -version
```

准备好 MySQL 实例（用于分片存储真实数据）

关闭防火墙 / 开放端口：`3307`（Proxy 默认端口）

### 下载安装

**下载解压**

```bash
# 下载 5.4.1
wget https://archive.apache.org/dist/shardingsphere/5.4.1/apache-shardingsphere-5.4.1-shardingsphere-proxy-bin.tar.gz
tar -zxvf apache-shardingsphere-5.4.1-shardingsphere-proxy-bin.tar.gz
mv apache-shardingsphere-5.4.1-shardingsphere-proxy-bin /opt/sharding-proxy
cd /opt/sharding-proxy
```

> 重要：后端是 MySQL，需要把 `mysql-connector-java-8.0.11.jar` 放到 `ext-lib` 目录（目录不存在手动新建）Apache Sha...

```bash
mkdir ext-lib
# 自行下载驱动放入 ext-lib
```
