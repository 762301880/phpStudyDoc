## ShardingSphere-Proxy(待补充)

> ShardingSphere-Proxy 是一个数据库代理，服务端程序，支持 MySQL/PostgreSQL 协议；客户端可以直接用 MySQL 连接工具连接，无需改业务代码，适合做分库分表、读写分离。 环境：Linux（CentOS / Ubuntu），JDK8+，MySQL 版本：5.4.1（稳定版，推荐）

**中文文档**

[shardingsphere中文文档地址](https://shardingsphere.apache.org/document/current/cn/overview/)

**目录结构**

```bash
sharding-demo/
├── conf/                                  【代理配置目录，挂载进容器】
│   ├── config-sharding.yaml               分片规则配置（数据源 + 分片算法）
│   └── server.yaml                        代理服务配置（模式 / 权限 / 全局属性）
│
├── ext-lib/                               【第三方驱动目录，挂载进容器】
│   └── mysql-connector-j-8.0.33.jar       MySQL JDBC 驱动（必须，否则无法连接后端）
│
├── mysql-init/                            【后端建表脚本】
│   └── init.sql                           原始建表脚本（db0/db1 双库版，保留作参考）
├── docker-compose.yml                     容器编排定义
└── 官方文档对照速查.md                     配置项 ↔ 官方文档链接对照
```

**ext-lib 下的jar包下载**

```bash
wget https://repo1.maven.org/maven2/com/mysql/mysql-connector-j/8.0.33/mysql-connector-j-8.0.33.jar
```

**docker-compose.yml**

```bash
version: "3.8"
services:
  sharding-proxy:
    image: apache/shardingsphere-proxy:5.4.1
    container_name: sharding-proxy
    ports:
      - "3307:3307"
    volumes:
      - ./conf:/opt/shardingsphere-proxy/conf
      # 新增这一行，挂载驱动目录
      - ./ext-lib:/opt/shardingsphere-proxy/ext-lib
    restart: unless-stopped
```



**conf\server.yaml**

> [**mode配置**](https://shardingsphere.apache.org/document/current/cn/user-manual/common-config/builtin-algorithm/metadata-repository/)   4用户手册→4.3.通用配置→内置算法→元数据持久化仓库
>
> [**authority配置**](https://shardingsphere.apache.org/document/current/cn/user-manual/shardingsphere-proxy/yaml-config/authority/)  4用户手册→4.2→YAML配置→认证和授权

```bash
# server.yaml
mode:
  type: Standalone

authority:
  users:
    - user: root@%
      password: "123456"
  privilege:
    type: ALL_PERMITTED

props:
  sql-show: true
```

**conf\config-sharding.yaml**

```bash
schemaName: sharding_db
dataSources:
  ds0:
    url: jdbc:mysql://mysql7.sqlpub.com:3312/laravel_test?serverTimezone=Asia/Shanghai&useSSL=false
    username: laravel_test
    password: GyquqF4seiPhk9QU

rules:
  - !SHARDING
    tables:
      t_order:
        actualDataNodes: ds0.t_order_0,ds0.t_order_1
        tableStrategy:
          standard:
            shardingColumn: user_id
            shardingAlgorithmName: t_order_mod

    shardingAlgorithms:
      t_order_mod:
        type: INLINE
        props:
          #表级分片策略只需产出表名部分(数据源前缀由 actualDataNodes 决定)
          #若写成 ${user_id % 2} 只会得到 0,无法匹配 t_order_0 / t_order_1
          algorithm-expression: t_order_${user_id % 2}
```
