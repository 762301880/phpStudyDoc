## 一,业务场景

> 两个是独立 PHP 项目，不同服务、不同数据库，无法直接使用本地数据库事务，**不能用 `beginTransaction/commit/rollback` 跨库跨服务**。

- TP 项目接口调用 Laravel 项目接口；
- 操作 A 库 (TP) 成功，操作 B 库 (Laravel) 失败，出现数据不一致。

## 二,SAGA 模式（补偿事务-推荐此方案)

### 介绍

SAGA 是**分布式事务**的一种设计模式，用来解决微服务场景下，跨多个服务、多个数据库的事务一致性问题。

> 传统本地数据库事务（ACID）在微服务行不通：每个微服务有自己独立数据库，无法用一个数据库事务把全部操作包起来。SAGA 提供最终一致性方案，**不保证强一致性，保证最终一致**。

**核心思想**

把一个大的分布式事务，拆分成一串本地子事务：

1. 每个子事务，在自己服务内执行（本地数据库事务，保证 ACID）
2. 每个子事务都要有对应的**补偿操作（回滚操作）**
3. 如果某一步失败，就依次执行前面已经成功步骤的补偿操作，撤销已完成的业务，达到整体回滚效果

> 重点：SAGA 没有真正的数据库回滚，是**业务层面的补偿回滚**。

### SAGA两种执行模式

#### 1. 编排式（Orchestration）

有一个**Saga 协调器**，由协调器指挥各个服务依次执行子事务。

- 协调器：知道整个业务流程，调用服务 A→服务 B→服务 C；失败就调用各补偿接口
- 优点：业务流程集中管理，服务只需要实现业务 + 补偿接口，服务之间不耦合
- 缺点：协调器变成单点，流程复杂后协调器逻辑很重

示例：下单：协调器调用扣库存→创建订单→扣余额；扣余额失败，则依次调用补偿：恢复余额、取消订单、恢复库存。

#### 2. 编排式（Choreography，也叫协同式）

**没有中心协调器**，各个服务之间通过事件消息互相触发下一步。

- 服务 A 做完本地事务，发事件消息；服务 B 监听消息，执行自己的事务，再发消息；
- 失败时发送回滚事件，各个服务监听补偿事件执行回滚。
- 优点：无中心节点，简单流程很清爽
- 缺点：流程分散在各个服务中，流程逻辑埋在消息里，复杂业务很难看懂链路，排查困难

### SAGA 重要特点

1. ✅ **最终一致性**：不是强一致，允许中间短暂数据不一致，最终业务状态一致
2. ❗ **补偿操作必须幂等**：补偿接口可以被多次调用，不能重复扣 / 加数据
3. ❗ **没有锁**，不会长时间占用资源，适合高并发微服务
4. 不支持隔离性（会出现脏读），业务上要考虑中间状态对外部的影响

### 举个通俗例子：电商下单

大事务：扣库存 → 创建订单 → 扣用户余额

1. 扣库存（成功）
2. 创建订单（成功）
3. 扣余额（失败）

SAGA 回滚：

- 补偿：取消订单
- 补偿：归还库存

最后整体回到下单前状态。

### 适用场景

微服务跨多库事务，无法使用本地事务，能接受**最终一致性**，业务可以实现补偿回滚逻辑。

> 不适合：要求实时强一致、很难写补偿逻辑的业务。



## 三,场景案例

### 前提梳理

1. 两个项目：独立部署，HTTP 接口互相调用（也可能 gRPC），数据库可能是不同 MySQL 实例。
2. 核心痛点：
   - TP 执行成功，调用 Laravel 接口报错 → TP 的数据已经落库，Laravel 没执行，数据脏了。
   - Laravel 执行成功，TP 后续报错 → Laravel 数据已经落库，TP 回滚不了对方数据库。

> ⚠️ 直接 HTTP 调用 + 本地事务是大坑：

```php
// ThinkPHP 错误示范！！
Db::startTrans();
try{
    Db::table('order')->save($order);
    // http调用laravel服务
    $res = http_post('http://laravel-service/api/create_bill',$param);
    if(!$res) throw new Exception();
    Db::commit();
}catch(\Exception $e){
    Db::rollback();
}
```

**问题：HTTP 调用成功之后，commit 之前服务宕机，Laravel 已经执行业务，TP 没 commit，两边不一致。**

### saga核心

每一个业务操作，都提供一个**正向执行接口** + **反向补偿回滚接口**。 流程举例：创建订单 (TP) → 创建账单 (Laravel)

### **状态表**：需要公共库（可以放 TP 库，也可以独立库）记录整个分布式流程状态

```sql
CREATE TABLE `saga_task` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `saga_no` varchar(64) NOT NULL COMMENT '全局事务编号，全局唯一，两个项目都要携带',
  `status` tinyint NOT NULL DEFAULT '0' COMMENT '0进行中 1成功 2失败待补偿 3全部补偿完成',
  `steps` json NOT NULL COMMENT '步骤列表，记录每一步状态、参数、补偿接口地址',
  `create_time` datetime DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_saga_no` (`saga_no`)
) ENGINE=InnoDB;
```

### 完整流程

1. **ThinkPHP 生成全局 saga_no（分布式事务 ID）写入 saga_task，状态 = 进行中**

2. 步骤1：TP 执行本地业务（创建订单），本地数据库事务提交；记录 步骤1 状态成功。

3. 步骤2：HTTP 调用 Laravel 的正向业务接口，

   请求头 / 参数带上 saga_no

   - Laravel 收到 `saga_no`，执行业务，返回成功；记录 步骤2 成功。

4. 全部步骤成功 → saga_task 更新状态 = 成功。

### 故障分支（任意一步失败）

情况 A：步骤2 Laravel 调用失败（超时、报错）

1. TP 捕获异常，更新 saga_task 状态 = 待补偿
2. 按照逆序调用每个已经成功步骤的补偿回滚接口
   - 先调用 Laravel 的补偿接口：撤销刚才创建账单（根据 saga_no 做撤销）
   - 再调用 TP 自己本地补偿接口：删除 / 撤销订单
3. 全部补偿执行完，saga_task 标记补偿完成。

### 关键点

1. **所有业务接口、补偿接口必须支持幂等！** 同一个 saga_no 重复调用不能重复创建数据。
2. 补偿接口不能抛业务异常，如果网络超时，要有**定时任务重试补偿**。
3. Laravel 侧，所有业务表，必须存`saga_no`字段，用来定位需要回滚的数据。

### Laravel 侧接口规范示例

正向接口：`POST /api/bill/create` 入参：`saga_no,xxx业务参数`，保存 bill 记录同时存`saga_no`。

补偿回滚接口：`POST /api/bill/compensate` 入参：`saga_no`，根据 saga_no 找到账单，执行撤销（软删除 / 状态改为作废），返回成功。

> 不能物理删除优先软删除，方便排查。

> 幂等处理：收到 saga_no 先查是否已经处理过，处理过直接返回成功，不要重复执行业务。

### 定时任务兜底（非常重要）

写定时脚本，扫描 `saga_task` 状态 = 待补偿，补偿未完成的任务，自动执行补偿回滚，解决网络抖动、进程宕机导致补偿逻辑没跑完。

### 简单业务落地建议

1. 如果业务是同步调用（调用完需要马上拿到结果）：

   SAGA 补偿模式

   - 新建 saga_task 表；双方接口增加 saga_no 参数；每个业务编写补偿回滚接口；增加定时任务兜底补偿。

2. 如果允许异步处理，不需要同步返回：**本地消息表 + MQ**，开发量最小。

```sql
  UNIQUE KEY `uk_saga_no` (`saga_no`),
```

#### SagaOrderService.php 核心业务服务（带完整失败处理）

```php
<?php
namespace app\service;

use app\model\Order;
use app\model\SagaTask;
use think\facade\Db;
use GuzzleHttp\Client;
use GuzzleHttp\Exception\RequestException;

class SagaOrderService
{
    //laravel服务地址
    protected string $laravelBaseUrl = 'http://127.0.0.1:8000';

    /**
     * 创建订单+调用laravel生成账单 SAGA主入口
     * @param float $amount
     * @return array
     * @throws \Exception
     */
    public function createOrderWithBill(float $amount): array
    {
        //1.生成全局唯一saga编号，整个分布式事务的凭证
        $sagaNo = uuid_create(UUID_TYPE_RANDOM);

        // 初始化saga任务记录，状态：进行中
        $sagaTask = SagaTask::create([
            'saga_no' => $sagaNo,
            'biz_type' => 'order_create',
            'status' => SagaTask::STATUS_RUNNING,
            'steps' => [], //步骤数组，后续填充
            'error_msg' => ''
        ]);

        // 定义整个saga流程所有步骤，顺序执行；补偿是逆序执行
        $steps = [
            [
                'step_name' => 'tp_create_order',
                'is_done' => false, //该步骤是否执行成功
                // tp本地步骤，不需要http地址，补偿是本地方法
                'compensate_type' => 'local',
                'compensate_method' => 'compensateTpOrder', //本地补偿方法名
                'params' => ['saga_no' => $sagaNo],
            ],
            [
                'step_name' => 'laravel_create_bill',
                'is_done' => false,
                'compensate_type' => 'http',
                'forward_url' => $this->laravelBaseUrl . '/api/bill/create', //正向执行接口
                'compensate_url' => $this->laravelBaseUrl . '/api/bill/compensate', //补偿回滚接口
                'query_url' => $this->laravelBaseUrl . '/api/bill/query-by-saga', //查询状态接口！！超时必须用
                'params' => [
                    'saga_no' => $sagaNo,
                    'amount' => $amount
                ]
            ]
        ];

        //更新saga任务，存入步骤配置
        $sagaTask->steps = $steps;
        $sagaTask->save();

        // ========= Step1：TP本地创建订单，本地数据库事务 =========
        Db::startTrans();
        try {
            $order = Order::create([
                'saga_no' => $sagaNo,
                'order_no' => 'ORD' . date('YmdHis'),
                'amount' => $amount,
                'status' => 1
            ]);
            Db::commit();

            //标记step1完成
            $steps[0]['is_done'] = true;
            $sagaTask->steps = $steps;
            $sagaTask->save();
        } catch (\Exception $e) {
            Db::rollback();
            // step1本地就失败，直接标记saga结束，不需要补偿，因为本地没提交数据
            $sagaTask->status = SagaTask::STATUS_COMPENSATE_OK;
            $sagaTask->error_msg = 'TP创建订单失败：' . $e->getMessage();
            $sagaTask->save();
            throw new \Exception("创建订单失败：" . $e->getMessage());
        }

        // ========= Step2：调用Laravel远程接口创建账单 =========
        $client = new Client(['timeout' => 5.0]);
        $laravelStepIndex = 1;
        $laravelStep = $steps[$laravelStepIndex];
        try {
            $resp = $client->post($laravelStep['forward_url'], [
                'json' => $laravelStep['params']
            ]);
            $body = json_decode($resp->getBody()->getContents(), true);
            if (!isset($body['code']) || $body['code'] !== 0) {
                //业务返回失败，进入补偿流程
                throw new \Exception('Laravel业务返回失败:' . ($body['msg'] ?? ''));
            }
            //远程调用成功，标记step2完成
            $steps[$laravelStepIndex]['is_done'] = true;
            $sagaTask->steps = $steps;
            $sagaTask->status = SagaTask::STATUS_SUCCESS;
            $sagaTask->save();

            return [
                'saga_no' => $sagaNo,
                'order_id' => $order->id,
                'msg' => '全部业务执行成功'
            ];

        } catch (RequestException $httpException) {
            // 网络异常：连接失败、超时、500等，**这里不能直接判定对方没执行！！**
            // 重点：调用查询接口，确认laravel那边这个saga_no到底有没有执行成功
            $isRemoteExecSuccess = $this->queryLaravelStepStatus($sagaNo);
            if ($isRemoteExecSuccess) {
                //！！！网络超时，但远端实际已经执行成功，业务算成功，更新状态直接返回
                $steps[$laravelStepIndex]['is_done'] = true;
                $sagaTask->steps = $steps;
                $sagaTask->status = SagaTask::STATUS_SUCCESS;
                $sagaTask->save();
                return [
                    'saga_no' => $sagaNo,
                    'order_id' => $order->id,
                    'msg' => '网络波动，远端实际执行成功'
                ];
            }
            //远端确实没有执行成功，需要补偿已经成功的步骤（step1 TP订单）
            $sagaTask->status = SagaTask::STATUS_NEED_COMPENSATE;
            $sagaTask->error_msg = "调用laravel http异常:" . $httpException->getMessage();
            $sagaTask->save();

            //【重要】不要在这里同步执行补偿！！如果补偿的时候网络挂掉，代码终止，任务留在 need_compensate
            // 丢给异步任务（队列）去做补偿；如果没有队列，就依靠定时任务扫描saga_task表
            $this->pushCompensateJob($sagaNo);

            throw new \Exception("调用账单服务异常，已触发补偿：" . $httpException->getMessage());

        } catch (\Exception $businessException) {
            //业务逻辑抛出异常，远端执行失败，需要补偿
            $sagaTask->status = SagaTask::STATUS_NEED_COMPENSATE;
            $sagaTask->error_msg = $businessException->getMessage();
            $sagaTask->save();

            $this->pushCompensateJob($sagaNo);
            throw new \Exception("分布式事务失败，触发补偿：" . $businessException->getMessage());
        }
    }

    /**
     * 查询laravel这个saga_no对应的业务是否执行成功（解决http超时问题）
     */
    public function queryLaravelStepStatus(string $sagaNo): bool
    {
        $client = new Client(['timeout' => 3]);
        try {
            $resp = $client->get($this->laravelBaseUrl . '/api/bill/query-by-saga', [
                'query' => ['saga_no' => $sagaNo]
            ]);
            $body = json_decode($resp->getBody()->getContents(), true);
            //code=0并且data存在，代表远端业务已经生成
            if (isset($body['code']) && $body['code'] === 0 && !empty($body['data'])) {
                return true;
            }
            return false;
        } catch (\Exception $e) {
            //查询接口本身也超时，返回false，交给定时任务兜底
            return false;
        }
    }

    /**
     * 推送补偿任务到异步队列；如果没有队列，这里可以空实现，完全依赖定时任务扫描saga_task
     */
    protected function pushCompensateJob(string $sagaNo)
    {
        // 如果你有thinkphp-queue，就投递队列：CompensateSagaJob::dispatch($sagaNo);
        // 如果没有队列，直接return，完全靠定时任务扫描status=2的记录执行补偿
        return;
    }

    /**
     * 【补偿入口】执行saga补偿，逆序执行所有is_done=true的步骤的补偿逻辑
     * 可以被队列调用，也可以被定时任务调用
     */
    public function doCompensate(string $sagaNo): void
    {
        $sagaTask = SagaTask::where('saga_no', $sagaNo)->find();
        if (!$sagaTask) {
            return;
        }
        //不是待补偿状态直接退出
        if ($sagaTask->status !== SagaTask::STATUS_NEED_COMPENSATE) {
            return;
        }
        $steps = $sagaTask->steps;
        // 逆序遍历步骤！！先补偿后面执行成功的，再补偿前面
        $reverseSteps = array_reverse($steps);
        $allCompensateOk = true;
        $errorMsgList = [];

        foreach ($reverseSteps as $step) {
            //只补偿已经执行成功的步骤
            if (!$step['is_done']) {
                continue;
            }
            try {
                if ($step['compensate_type'] === 'local') {
                    //本地补偿，调用本类的补偿方法
                    $method = $step['compensate_method'];
                    $this->$method($step['params']);
                } elseif ($step['compensate_type'] === 'http') {
                    //远程http补偿接口调用
                    $client = new Client(['timeout' => 5]);
                    $resp = $client->post($step['compensate_url'], [
                        'json' => $step['params']
                    ]);
                    $ret = json_decode($resp->getBody()->getContents(), true);
                    if (!isset($ret['code']) || $ret['code'] !== 0) {
                        throw new \Exception("远程补偿返回业务失败:" . json_encode($ret));
                    }
                }
            } catch (\Exception $e) {
                $allCompensateOk = false;
                $errorMsgList[] = "step:{$step['step_name']} 补偿失败:" . $e->getMessage();
            }
        }

        if ($allCompensateOk) {
            //全部补偿成功
            $sagaTask->status = SagaTask::STATUS_COMPENSATE_OK;
        } else {
            //部分补偿失败，标记人工介入，后续定时任务会重复重试该任务
            $sagaTask->status = SagaTask::STATUS_COMPENSATE_FAIL;
        }
        $sagaTask->error_msg .= "\n补偿日志:" . implode(";", $errorMsgList);
        $sagaTask->save();
    }

    /**
     * TP本地补偿：作废订单，幂等
     */
    public function compensateTpOrder(array $params): void
    {
        $sagaNo = $params['saga_no'];
        //幂等：已经作废直接返回，不要重复操作
        $order = Order::where('saga_no', $sagaNo)->find();
        if (!$order || $order->status === 9) {
            return;
        }
        $order->status = 9;
        $order->save();
    }
}
```

####  ThinkPHP 定时任务脚本（超级重要兜底！！）

> 不管队列挂掉、进程崩溃、补偿的时候网络中断，这个定时脚本保证一定会重试补偿 每分钟执行一次：扫描当天 `status=2 或者 status=4` 的 saga 任务，调用`doCompensate`

```php
<?php
// command 命令行脚本
namespace app\command;

use app\service\SagaOrderService;
use app\model\SagaTask;
use think\console\Command;
use think\console\Input;
use think\console\Output;

class SagaCompensateTask extends Command
{
    protected function configure()
    {
        $this->setName('saga:compensate')
            ->setDescription('saga补偿兜底定时任务');
    }

    protected function execute(Input $input, Output $output)
    {
        $service = new SagaOrderService();
        //查询待补偿、补偿失败需要重试的任务
        $list = SagaTask::whereIn('status', [
            SagaTask::STATUS_NEED_COMPENSATE,
            SagaTask::STATUS_COMPENSATE_FAIL
        ])->limit(20)->select();

        foreach ($list as $item) {
            $output->writeln("开始补偿 saga_no:{$item->saga_no}");
            try {
                $service->doCompensate($item->saga_no);
            } catch (\Exception $e) {
                $output->writeln("补偿异常:" . $e->getMessage());
            }
        }
        return self::SUCCESS;
    }
}
```

> 配置 crontab：`*/1 * * * * php think saga:compensate >> runtime/saga-compensate.log`

#### BillController.php

```php
<?php
namespace App\Http\Controllers;
use App\Models\Bill;
use Illuminate\Http\Request;

class BillController extends Controller
{
    /**
     * 正向创建账单，幂等
     */
    public function create(Request $request)
    {
        $sagaNo = $request->input('saga_no');
        $amount = $request->input('amount');

        //幂等！同一个saga_no已经存在直接返回成功，不重复创建
        $bill = Bill::where('saga_no', $sagaNo)->first();
        if ($bill) {
            return response()->json(['code' => 0, 'msg' => 'ok', 'data' => $bill]);
        }
        $bill = Bill::create([
            'saga_no' => $sagaNo,
            'order_id' => 0,
            'amount' => $amount,
            'status' => 1
        ]);
        return response()->json(['code' => 0, 'msg' => 'ok', 'data' => $bill]);
    }

    /**
     * 补偿回滚，作废账单，幂等
     */
    public function compensate(Request $request)
    {
        $sagaNo = $request->input('saga_no');
        $bill = Bill::where('saga_no', $sagaNo)->first();
        if (!$bill || $bill->status === 9) {
            //没有数据或者已经作废，幂等直接返回成功
            return response()->json(['code' => 0, 'msg' => '已经作废']);
        }
        $bill->status = 9;
        $bill->save();
        return response()->json(['code' => 0, 'msg' => '补偿作废成功']);
    }

    /**
     * 查询saga_no是否已经执行业务，给TP超时探测
     */
    public function queryBySaga(Request $request)
    {
        $sagaNo = $request->input('saga_no');
        $bill = Bill::where('saga_no', $sagaNo)->first();
        return response()->json([
            'code' => 0,
            'data' => $bill
        ]);
    }
}
```
