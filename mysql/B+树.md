## sql表

```sql
-- 聚簇索引（主键id就是B+树的排序key）
CREATE TABLE bplus_demo (
    id INT PRIMARY KEY COMMENT '主键，B+树排序字段',
    name VARCHAR(32) NOT NULL,
    create_time DATETIME
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## B + 树特点：

1. **所有数据都在叶子节点**；非叶子节点只存索引键 + 页指针，不存真实行数据
2. 叶子节点用双向链表串起来，范围查询非常快
3. 多路平衡查找树，所有叶子节点高度一致

```mysql
                    ┌─────────────────────────────┐
                    │         根节点(非叶子页)      │
                    │  [10 ,  30 ,  60] 指针      │
                    └───────┬────────┬────────────┘
                            │        │
          ┌─────────────────┘        └────────────────┐
          ▼                                           ▼
┌──────────────────────┐                  ┌──────────────────────────┐
│  分支节点(非叶子页)   │                  │    分支节点(非叶子页)     │
│ [3,7] 指针           │                  │  [40,50,80] 指针         │
└─────┬──────┬─────────┘                  └──────┬────────┬───────────┘
      │      │                                   │        │
      ▼      ▼                                   ▼        ▼
┌────────┐ ┌────────┐               ┌────────────┐      ┌────────────┐
│叶子节点│ │叶子节点│               │ 叶子节点    │      │ 叶子节点   │
│1,2,3   │ │4,5,6,7 │               │30,35,40,45,50│    │60,70,80,90,100│
│(完整行)│ │(完整行)│               │(完整行)     │      │(完整行)    │
└────────┘ └────────┘               └────────────┘      └────────────┘
     │          │                         │                     │
     └──────────┼─────────────────────────┼─────────────────────┘
                ←──────双向链表指针互相连接────────────────→
```

### 拆解每个部分

1. **非叶子节点（根、分支节点）** 只存索引键 + 指向子页的指针，**不存真实数据行**。作用是路由查找，快速定位去哪一个叶子页。 InnoDB 一页默认 16KB，可以存非常多索引键，所以树高通常很小：一般 2~3 层就可以存千万级数据。
2. **叶子节点（最底层）⭐最重要**

- 保存**完整的行数据（主键聚簇索引）**
- 所有叶子节点通过链表相连 → `where id between 20 and 70` 范围查询，找到起点后顺着链表向后遍历，不用回到上层节点。

和 B 树简单对比（一眼看懂 B + 树优势）

B 树：每个节点既存 key 又存数据；查找时有可能在中间节点就命中返回。 B + 树：**只有叶子存全部数据**，非叶子纯做索引导航；全部查询最后都落到叶子节点，范围查询极强。

**举个例子：查询 id=40**

1. 从根节点 `[10,30,60]` 判断，40 大于 30、小于 60 → 走第二个分支节点
2. 分支节点`[40,50,80]`判断，落到对应叶子页
3. 在叶子页内部找到 id=40 的完整行记录。
