## 必须必备

1 服务器 (例如华为云)

2 域名 (例如腾讯云域名)

## 个人备案:

所需材料: 负责人身份证、本人人脸核验、手机号、应急联系人 

例如我服务器是华为云的 域名是腾讯云的 

> 腾讯云这边只需要把域名解析到华为云服务器ip,还要下载对应的域名证书
>
> 然后备案打开华为云官网 搜索备案 需要在华为云中填写备案信息

**docker-compose.yml**

```dockerfile
version: '3.8'
services:
  nginx:
    image: nginx:alpine
    container_name: beian-page
    restart: always
    ports:
      - "80:80"
    volumes:
      - ./html:/usr/share/nginx/html
    environment:
      - TZ=Asia/Shanghai
```

启动命令

```bash
# 进到 site 目录
cd site

# 启动
docker-compose up -d

# 查看日志
docker-compose logs -f
```
