## 安装

### docker安装Memcached

1. 拉取镜像

```bash
# 拉取最新稳定版
docker pull memcached
# 指定版本示例（推荐固定版本）
# docker pull memcached:1.6.27
```

2. 启动容器（常用两种方案）

  方案① 简易启动（无密码）

  ```bash
docker run -d \
  --name memcached \
  -p 11211:11211 \
  --restart always \
  memcached
  ```

  方案② 带内存限制 + 设置密码（生产推荐）

```bash
docker run -d \
  --name memcached \
  -p 11211:11211 \
  --restart always \
  memcached \
  memcached -m 256 -S
```

参数说明：

- `-m 256`：最大可用内存 256MB
- `-S`：启用 SASL 密码认证

> 设置密码需要进入容器操作：

```bash
# 进入容器
docker exec -it memcached sh
# 使用 saslpasswd2 创建用户
saslpasswd2 -a memcache root
# 输入自定义密码
```

3. 持久化数据（可选）

   Memcached 默认内存存储，重启丢失数据；如需持久化启用 `-M` + 开启 slab 存储或者使用 `memcached-tool`，更常用方式：挂载卷保存 SASL 账号文件

```ba
mkdir -p /data/memcached/sasl
```

4. 常用管理命令

```bash
# 查看运行状态
docker ps | grep memcached

# 进入容器终端
docker exec -it memcached sh

# 重启
docker restart memcached

# 停止
docker stop memcached

# 删除容器
docker rm -f memcached
```

5. Docker Compose 方式（推荐服务器使用）

```bash
version: '3'
services:
  memcached:
    image: memcached:1.6.27
    container_name: memcached
    ports:
      - "11211:11211"
    restart: always
    command: memcached -m 256
```

启动

```bash
docker-compose up -d
```
