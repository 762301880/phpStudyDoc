**反射：程序运行的时候，动态获取类、方法、属性、参数、注释这些信息，还能动态调用方法、修改属性，不需要提前硬编码写死。**

> 普通写法：代码写死 `$obj->test()` 反射：运行时才知道类名、方法名，动态去执行。

命名空间：`ReflectionClass`、`ReflectionMethod`、`ReflectionProperty` …

## 核心作用

### **动态解析类结构（运行时读信息）** 

不用打开源码文件，代码直接读取：类名、所有方法、属性、方法参数、返回类型、注释文档、是否私有 /protected。

```php
<?php

class User
{
    public string $name;
    private int $age;

    public function hello(string $msg): string
    {
        return $msg;
    }
}

//反射示例
$ref = new ReflectionClass(User::class);

var_dump($ref->getMethods()); //获取全部方法
var_dump($ref->getProperties()); //获取所有属性
$method = $ref->getMethod('hello');
var_dump($method->getParameters()); //读取方法参数列表
echo $ref->getDocComment(); //读取类上面的注释
```

### **实例化对象，类名是字符串（动态创建对象）** 

不知道类具体名字，字符串传类名就 new 对象

```php
$className = "User";
$ref = new ReflectionClass($className);
$obj = $ref->newInstance(); //等价 new User()
```

### 调用私有、受保护方法 / 访问私有属性（绕过访问控制）

> 业务尽量少用，框架大量用。

```php
$refProp = $ref->getProperty('age');
$refProp->setAccessible(true); //解除private保护
$refProp->setValue($obj, 22); //给私有属性赋值
echo $refProp->getValue($obj); //读取私有属性
```

### 动态调用方法

```php
$refMethod = $ref->getMethod('hello');
$res = $refMethod->invoke($obj, ["hi反射"]);
echo $res;
```

## 哪些地方大量用到反射（工作项目）

### 1. ThinkPHP / Laravel 容器 IOC 依赖注入（最典型）

框架控制器，方法自动注入对象：

```php
public function index(UserService $service){}
```

框架就是靠**反射读取方法参数类型，自动实例化类传入**，不用手动 new。

### 2. 注解解析（PHP8 Attribute）

读取类 / 方法上注解，做路由、权限校验。 ThinkPHP 路由注解、Laravel 注解全部基于反射。

### 3. 文档生成工具

自动读取类注释、方法注释生成接口文档。

### 4. ORM 模型

比如模型自动映射数据库字段，解析属性。

### 5. RPC、API 网关

传入字符串类名 + 方法名，后端动态执行对应服务方法。



## 优缺点

### 优点

- **运行时动态获取代码元信息**，实现 IOC 容器、注解，是框架底层核心基石。
- 可以访问私有成员。

### 缺点

1. **性能较差**，反射比直接调用慢，不要循环大批量反射。框架内部使用，业务代码尽量避免滥用。
2. 破坏封装：强行访问 private 属性，代码可读性变差。
3. 代码重构时，反射字符串类名 IDE 无法检测，容易出现 bug。

## 面试总结

PHP 反射允许程序在运行时获取类、方法、属性的元数据，动态实例化、调用方法，是框架 IOC 依赖注入、注解功能的底层实现；但是有性能损耗，业务不要滥用。
