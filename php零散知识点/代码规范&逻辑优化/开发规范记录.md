## 数据列表返回前端列命

> 例如如下的示例代码,列表添加对应的返回字段映射,前端可以根据返回渲染列表
>
> 这样做的好处是如果后期新增或者删减字段不用麻烦前端后端可以做处理

**示例代码**

```php
 protected static function getFields()
    {
        return [
            ['field' => 'id', 'title' => '主键', 'is_show' => true],
            ['field' => 'name', 'title' => '分类名称', 'is_show' => true],
            ['field' => 'pid', 'title' => '请求方式', 'is_show' => false],
            ['field' => 'status', 'title' => '状态', 'is_show' => false],
            ['field' => 'level', 'title' => '等级', 'is_show' => false],
        ];
    }

    public function index(Request $request)
    {
       $params = $request->only(['status', 'name', 'page', 'limit']);
        $limit = $params['limit'] ?? PaginateService::LIMIT_DEFAULT;
        $res = \App\Models\Shop\Category::query()
            ->where('pid',0)
            ->with('children')->paginate($limit);
        PaginateService::appendDataToPaginate($res, ['fields' => self::getFields()]);
        return $this->success('分类列表返回成功', $res);
    }
```

## URL 路径版本化 / URI 路径版本控制

- **中文：URL 路径版本化 / URI 路径版本控制**
- **英文：Path Versioning / URI Path Versioning**
- 统称：**API 版本控制（API Versioning）**

**路径版本（最常用，Laravel 我们前面写的）** `/api/v1/user`，版本号写在 URL 路径里。

### URL 路径版本（最常用 `api/v1/xxx`）

路由：`routes/api.php`

```php
// routes/api.php
Route::prefix('v1')->group(function () {
    Route::get('user', [\App\Http\Controllers\Api\V1\UserController::class, 'index']);
});

Route::prefix('v2')->group(function () {
    Route::get('user', [\App\Http\Controllers\Api\V2\UserController::class, 'index']);
});
```

目录结构

```php
app/Http/Controllers/Api
├─ V1
│   └─ UserController.php
└─ V2
    └─ UserController.php
```

> 请求地址：`/api/v1/user`、`/api/v2/user`

✅优点：

- 直观，一眼看出版本；日志、nginx 日志直接看到版本；调试简单
- Laravel 原生支持，无需额外中间件
- 第三方调用方最容易适配

❌缺点：

- 接口改动大时需要复制一份控制器代码，存在重复代码，需要抽公共 service 层

### 真实嵌套示例

**路由**

```php
Route::prefix('v1')->group(function () {
    Route::prefix('shop')->group(function () {
        // 分类
        Route::prefix('category')->group(function () {
            Route::get('index', [\App\Http\Controllers\V1\Shop\Category::class, 'index']);
        });
        // 商品
        Route::prefix('goods')->group(function () {
            Route::get('index', [\App\Http\Controllers\V1\Shop\GoodsController::class, 'index']);
        });
        // 订单
        Route::prefix('order')->group(function () {
            Route::get('list', [\App\Http\Controllers\V1\Shop\OrderController::class, 'list']);
        });
    });
});

# 请求示例
/api/v1/shop/category/index
```
