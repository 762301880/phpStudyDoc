## 常用dao查询命名规范

```php
# 查询来自id
public static function findById()

# 查询存在于父级id下的id
public static function findInParentIds()
    
# 查询存在于员工编号的员工    
public static function findStaffByStaffNumber($staff_number)    
  
# 查询某个手机号下的所有编号    
public static function getMessageNosByMobile($mobile): array    
    
# 生成编号
public static function generateMessageNo()

# 获取机构主键
public static function getOrgIdByStaffNumber($staff_number)
```

## 数据列表返回前端列命

> 例如如下的示例代码,列表添加对应的返回字段映射,前端可以根据返回渲染列表
>
> 这样做的好处是如果后期新增或者删减字段不用麻烦前端后端可以做处理

**示例代码**

```php
 protected static function getFields()
    {
        return [
            ['field' => 'id', 'title' => '主键', 'is_show' => true],
            ['field' => 'name', 'title' => '分类名称', 'is_show' => true],
            ['field' => 'pid', 'title' => '请求方式', 'is_show' => false],
            ['field' => 'status', 'title' => '状态', 'is_show' => false],
            ['field' => 'level', 'title' => '等级', 'is_show' => false],
        ];
    }

    public function index(Request $request)
    {
        $params = $request->only(['status', 'name', 'page', 'limit']);
        $limit = $params['limit'] ?? PaginateService::LIMIT_DEFAULT;
        $res = \App\Models\Shop\Category::query()->with('children')->paginate($limit);
        PaginateService::appendDataToPaginate($res, ['fields' => self::getFields()]);
        return $this->success('分类列表返回成功', $res);
    }
```
