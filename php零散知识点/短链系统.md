## 什么是短链（短网址）

**短链 = 短网址** 把一个**很长的 URL 地址**，转换成一个很短的地址。

> 例： 长链接：`https://www.xxx.com/article/detail?id=123456789&name=abc&page=1` 短链接：`https://你的域名/s/Abc123`

访问短链时，服务器 301/302 重定向，跳转到原始长链接。

---

## 短链优点

1. 网址变短，适合微信、短信、二维码、社交媒体分享
2. 可以统计访问次数、访客 IP、访问时间
3. 后期可更换跳转目标（灵活管理）

---

## 实现原理

1. 用户提交长网址
2. 服务器生成唯一短码（`a-z A-Z 0-9`）
3. 数据库保存：`短码 <--> 原始长链接`
4. 访问 `域名/s/短码` → 程序查到长链接 → 302 重定向跳转

> 短码字符集：`0‑9,a‑z,A‑Z` 一共 62 个字符（62 进制）

---

## 什么情况下需要短链接

核心本质：

> 短链解决 3 件事：**网址太长、链接不能直接发、需要访问数据统计、后期可控跳转目标**

**强烈推荐使用短链的场景**

### 1、短信营销 / 短信通知

手机短信对字符有限制，长 URL 非常长： `shturl.cc/YZi7iwSwidv15nUuy21ziuwKyh3LYp8WzgkBu9NJcY3x1nXQw0RE7djsL7NAZ6d`

- 超长链接占大量短信字数，会导致**短信分成多条扣费，成本翻倍**
- 短信里长链接容易换行、断裂，点不开 👉 短链就几个字符，省短信费、不会断。

### 2、微信、QQ、抖音、小红书、社群、朋友圈转发

很多平台有规则：

- 直接发外部长链接会**被风控、屏蔽、限流、降权**
- 超长链接视觉很乱，用户看着不信任、不愿意点

> 注意：短链也不是万能免封，只是降低风险；违规内容用啥都会被封。

### 3、二维码

二维码内容越长，点阵越密集：

- 长网址生成的二维码**很复杂，扫码经常识别失败**
- 短链二维码图案简单，扫码成功率高很多

> 打印物料（海报、传单、名片、包装）几乎都会用短链。

### 4、需要统计推广效果（最核心商用场景）

长链接本身无法统计：谁点了、点了多少次、哪个渠道来的。

例子：你做 3 个渠道投放

- 抖音：`shturl.cc/HmvrerAzVektHZN7`
- 朋友圈：`shturl.cc/0ytBMiGaXj2r`
- 短信：`shturl.cc/PKBF8FeoNA9sl`

后台看每个短链点击量，就知道**哪个渠道效果最好**。

> 也就是常说的「渠道追踪、活码」。

### 5、后期要更换跳转目标（活码-重要）

打印好一批海报传单之后，活动页面地址变了。

- 如果印的是原始长网址 → 海报全部作废，只能重印，损失很大
- 如果印**短链**：后台修改短链跳转目标即可，海报不用改！ 👉 这个就是「活码」，短链一个非常强大的用途。

### 6、第三方平台字符严格限制

比如微博、一些广告文案、私信、评论区有字数上限。 超长链接吃掉大量文字名额，用短链节约字符。

### 7、美化、品牌形象

长串参数链接非常难看： `shturl.cc/tp7rIBWbqIYKNhjTrpWRE4QVRTQu60fUQYIyeJr7gumhuMAY2W5pAKJeWIdsAt3GqfzjQ` 对比 `shturl.cc/ddHkCq9WnEcm` 短链接清爽干净，用户信任感更高。

---

## 不需要、没必要做短链的场景

1. **自己网站内部跳转** 比如网站内页面 `a页面→b页面`，直接用原 URL 即可，完全没必要。
2. 链接本身就很短`https://www.baidu.com`，再缩短没有任何收益，多一层跳转反而慢一点。
3. 追求极致访问速度，流量超大并且跳转目标永久不变 短链多了一次 302 跳转；如果永久不会换目标，直接放原链接性能更好（可以用 301 永久跳转缓解）

---

## 对比表：要不要上短链

| 场景                  | 是否建议短链 | 核心原因                   |
| --------------------- | ------------ | -------------------------- |
| 短信群发              | ✅强烈建议    | 省字数防断裂，降低成本     |
| 海报二维码打印        | ✅强烈建议    | 扫码成功率高、后期可改地址 |
| 多渠道广告投放统计    | ✅强烈建议    | 区分每个渠道点击数据       |
| 微信群 / 私域转发推广 | ✅建议        | 链接简短美观，降低风控概率 |
| 网站内部页面跳转      | ❌不建议      | 额外增加跳转开销           |
| 本身就很短的网址      | ❌没必要      | 没有收益，徒增一层跳转     |

## 数据库设计（MySQL）

```sql
CREATE TABLE `short_url` (
  `id` int unsigned NOT NULL AUTO_INCREMENT COMMENT '自增主键ID',
  `short_code` varchar(10) NOT NULL COMMENT '短链唯一识别码',
  `long_url` text NOT NULL COMMENT '原始需要跳转的长网址',
  `click_count` int DEFAULT '0' COMMENT '累计点击访问次数',
  `expire_at` datetime DEFAULT NULL COMMENT '短链过期时间，NULL代表永不过期',
  `created_at` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '短链创建时间',
  `updated_at` datetime DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_short_code` (`short_code`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='短链地址数据表';
```

**可选的点击日志表**

```sql
CREATE TABLE `short_click_log` (
  `id` INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '日志自增主键',
  `short_code` VARCHAR(10) NOT NULL COMMENT '被访问的短链码',
  `ip` VARCHAR(50) NULL COMMENT '访客客户端IP地址',
  `user_agent` TEXT NULL COMMENT '访客浏览器/设备UA信息',
  `visit_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '本次访问发生时间',
  PRIMARY KEY (`id`),
  KEY idx_short_code (`short_code`) COMMENT '短链码查询索引'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='短链访问明细日志表';
```

## 服务类`service/ShortUrlService.php`

> 后期优化 加上redis

```php
<?php

namespace App\Services;

use App\Models\ShortUrl;
use App\Jobs\SyncShortUrlClickJob;
use App\Services\Abs\CommonService;
use Illuminate\Database\UniqueConstraintViolationException;

/**
 * 短链业务服务‑Redis缓存优化版
 * 适配自定义 RedisService，MySQL存全量，Redis按需缓存热点
 */
class ShortUrlService extends CommonService
{
    private const CHARS = '0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ';

    // redis key前缀
    private const CACHE_SHORT_URL_PREFIX = 'short:url:';
    private const CACHE_CLICK_PREFIX     = 'short:click:';

    // 永久有效短链缓存时长 7天
    private const CACHE_TTL_FOREVER = 86400 * 7;
    // 不存在短码的空缓存 防穿透 60秒
    private const NULL_CACHE_TTL = 60;

    protected RedisService $redis;

    public function __construct()
    {
        $this->redis = RedisService::getInstance();
    }

    /**
     * 生成8位随机短码
     * @return string
     */
    private function generateRandomCode(): string
    {
        $code = '';
        $maxIndex = strlen(self::CHARS) - 1;
        for ($i = 0; $i < 8; $i++) {
            $code .= self::CHARS[mt_rand(0, $maxIndex)];
        }
        return $code;
    }

    /**
     * 创建短链
     * @param string $longUrl
     * @param string|null $expireTime
     * @return string
     * @throws \Exception
     */
    public function create(string $longUrl, ?string $expireTime = null): string
    {
        // 相同长链接返回已有短链
        $exist = ShortUrl::where('long_url', $longUrl)->first();
        if ($exist) {
            $this->saveCache($exist);
            return $this->buildFullUrl($exist->short_code);
        }

        $maxRetry = 15;
        for ($attempt = 0; $attempt < $maxRetry; $attempt++) {
            try {
                $shortCode = $this->generateRandomCode();
                $row = ShortUrl::create([
                    'short_code'   => $shortCode,
                    'long_url'     => $longUrl,
                    'expire_at'    => $expireTime,
                    'click_count'  => 0,
                ]);
                $this->saveCache($row);
                return $this->buildFullUrl($shortCode);
            } catch (UniqueConstraintViolationException $e) {
                continue;
            }
        }
        throw new \Exception('短码生成失败，重试次数耗尽');
    }

    /**
     * 获取长链接 + 点击计数+1（Redis内存计数，不实时update数据库）
     * @param string $shortCode
     * @return ShortUrl|null
     */
    public function getLongUrlAndAddClick(string $shortCode): ?ShortUrl
    {
        $cacheKey = self::CACHE_SHORT_URL_PREFIX . $shortCode;
        $clickKey = self::CACHE_CLICK_PREFIX . $shortCode;

        $raw = $this->redis->get($cacheKey);

        // -------- 缓存命中 --------
        if ($raw !== false && $raw !== null) {
            $data = json_decode($raw, true);
            // 空标记：短码不存在
            if ($data === null) {
                return null;
            }
            // 判断短链是否过期
            if (!empty($data['expire_at']) && now()->gt($data['expire_at'])) {
                $this->redis->del($cacheKey);
                return null;
            }
            // redis计数器自增
            $this->redis->incr($clickKey);
            return new ShortUrl($data);
        }

        // -------- 缓存未命中，查询数据库 --------
        $info = ShortUrl::where('short_code', $shortCode)->first();
        if (!$info) {
            // 缓存空值防穿透
            $this->redis->setex($cacheKey, self::NULL_CACHE_TTL, json_encode(null));
            return null;
        }

        // 数据库查到但是已经过期
        if (!empty($info->expire_at) && now()->gt($info->expire_at)) {
            $this->redis->setex($cacheKey, self::NULL_CACHE_TTL, json_encode(null));
            return null;
        }

        // 回填缓存
        $this->saveCache($info);
        // 计数+1
        $this->redis->incr($clickKey);

        return $info;
    }

    /**
     * 写入短链数据到Redis缓存
     * @param ShortUrl $shortUrl
     */
    private function saveCache(ShortUrl $shortUrl): void
    {
        $cacheKey = self::CACHE_SHORT_URL_PREFIX . $shortUrl->short_code;

        $data = [
            'short_code' => $shortUrl->short_code,
            'long_url'   => $shortUrl->long_url,
            'expire_at'  => $shortUrl->expire_at,
        ];

        if ($shortUrl->expire_at) {
            $ttl = max(1, now()->diffInSeconds($shortUrl->expire_at));
        } else {
            // 永久短链缓存7天 + 随机抖动 防止雪崩
            $ttl = self::CACHE_TTL_FOREVER + rand(0, 1800);
        }

        $this->redis->setex($cacheKey, $ttl, json_encode($data));
    }

    /**
     * 拼接完整跳转url
     * @param string $shortCode
     * @return string
     */
    private function buildFullUrl(string $shortCode): string
    {
        return url("/s/{$shortCode}");
    }

    /**
     * 定时任务调用：批量同步Redis点击计数落地MySQL
     */
    public function syncClickCountToDb(): void
    {
        $prefix = self::CACHE_CLICK_PREFIX;
        $keys = $this->redis->keys($prefix . '*');

        foreach ($keys as $key) {
            $shortCode = str_replace($prefix, '', $key);
            $addNum = (int)$this->redis->get($key);
            if ($addNum <= 0) {
                $this->redis->del($key);
                continue;
            }
            // 推送到队列异步更新数据库
            SyncShortUrlClickJob::dispatch($shortCode, $addNum);
            $this->redis->del($key);
        }
    }
}

```

## 【生成短链】入口文件 `create_link.php`

> 这个文件就是用来新建短链，你访问这个页面就能生成

```php
<?php

// 引入短链服务类
require __DIR__.'/service/ShortUrlService.php';

// 实例化服务
$shortService = new ShortUrlService();

// ============你要缩短的长网址，改这里============
$longUrl = "article/detail?id=123456789&name=abc&page=1";
// 过期时间 null=永不过期
$expire = null;
// ================================================

// 调用服务生成短链
$shortUrl = $shortService->create($longUrl, $expire);

// 输出结果给你看
echo "原始长链接：".$longUrl."<br>";
echo "生成好的短链：<a href='{$shortUrl}' target='_blank'>{$shortUrl}</a>";
```

## 控制器跳转方法

`app/Http/Controllers/ShortUrlController.php`

```php
<?php

namespace App\Http\Controllers;

use App\Services\ShortUrlService;

class ShortUrlController extends Controller
{
    // 生成短链测试
    public function createDemo(ShortUrlService $service)
    {
        $longUrl = "https://www.baidu.com";
        $shortUrl = $service->create($longUrl);

        echo "原链接：{$longUrl}<br>";
        echo "短链地址：<a href='{$shortUrl}' target='_blank'>{$shortUrl}</a>";
    }

    /**
     * 短链重定向入口
     * @param string $code 短码
     */
    public function redirect(string $code, ShortUrlService $service)
    {
        $record = $service->getLongUrlAndAddClick($code);

        // 查不到 / 已过期
        if (!$record) {
            abort(404, '该短链不存在或者已过期');
        }

        // 302临时重定向（推荐短链使用）away 支持外部网址
        return redirect()->away($record->long_url);
    }
}
```
