## vue3集成

### 安装插件

```bash
npm install @tencentcloud/chat --save
# 上传图片、文件消息，需要上传插件
npm install tim-upload-plugin --save	
```

若同步依赖过程中出现问题，请切换 npm 源后重试。

```bash
npm config set registry http://r.cnpmjs.org/
```
