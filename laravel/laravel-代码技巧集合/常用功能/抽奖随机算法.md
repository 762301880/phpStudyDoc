## 抽奖注意事项

**大厂通用规范：**权重一律使用整数，禁止小数权重**

单纯权重随机只会导致运气抽奖，商业抽奖必须人为调控概率：

1. 每日 / 每人中奖上限

   用户一天最多中 1 次二等奖、终身只能中 1 次一等奖；

2. 时段概率调控

   大促期间提高奖品概率，凌晨调低大奖概率；

3. 中奖人数总量兜底

   比如 10000 次抽奖，严格控制一等奖刚好 10 个，不能随机浮动太大（纯随机会出现某次抽 20 个、某次 0 个）；

> 纯区间随机是浮动概率，总量不精准；大厂需要**固定总量派发**会搭配：蓄水池算法、配额发放。

4. 黑名单、防薅羊毛

   新用户概率偏高、老用户 / 批量注册小号压低大奖概率。



## [网络案例](https://www.jb51.net/article/139144.htm)

> 调用test 函数即可 逻辑比较简单
>
> 总体思路就是 将奖品数组组合成 key=>value 的键值对，key对应id，值对应概率
>
> 然后将组合的数组进入概率循环函数
>
> 返回结果之后得到中将项，数组中删除中奖项，并打乱未中奖项，最后 给用户返回中奖项和未中奖项 

```php
    public function test(Request $request)
    {
        //拼装奖项数组
        // 奖项id，奖品，概率
        $prize_arr = array(
            '0' => array('id' => 1, 'prize' => '平板电脑', 'v' => 1),
            '1' => array('id' => 2, 'prize' => '数码相机', 'v' => 0),
            '2' => array('id' => 3, 'prize' => '音箱设备', 'v' => 0),
            '3' => array('id' => 4, 'prize' => '4G优盘', 'v' => 5),
            '4' => array('id' => 5, 'prize' => '10Q币', 'v' => 0),
            '5' => array('id' => 6, 'prize' => '空奖', 'v' => 80),
        );
        foreach ($prize_arr as $key => $val) {
            $arr[$val['id']] = $val['v'];//概率数组
        }
        $rid = $this->get_rand($arr); //根据概率获取奖项id
        $res['yes'] = $prize_arr[$rid - 1]['prize']; //中奖项
        unset($prize_arr[$rid - 1]); //洗牌函数随机打乱，将中奖项从数组中剔除，剩下未中奖项
        shuffle($prize_arr); //打乱数组顺序 已经剔除抽到奖项的打乱顺序
        for ($i = 0; $i < count($prize_arr); $i++) {
            $pr[] = $prize_arr[$i]['prize'];  //未中奖项数组
        }
        $res['no'] = $pr;
// var_dump($res);
        if ($res['yes'] != '空奖') {
            $result['status'] = 1;
            $result['name'] = $res['yes'];
        } else {
            $result['status'] = -1;
            $result['msg'] = $res['yes'];
        }
//return $result;
        var_dump($result);
    }


    /**
     * 每一次循环下标 如果下标大于等于当前的随机数 直接将key赋值给结果
     * 反之则总精度减下标赋值给精度，然后再一次进入下一个下标循环
     * @param $proArr
     * @return int|string
     */
    public function get_rand($proArr)
    {
        $result = '';
        //概率数组的总概率精度
        $proSum = array_sum($proArr);
        // var_dump($proSum);
        //概率数组循环
        foreach ($proArr as $key => $proCur) {
            $randNum = mt_rand(1, $proSum);  //返回随机整数 随机的 1-10
            if ($randNum <= $proCur) { //如果 当前的随机整数小于等于当前的下标
                $result = $key; //直接赋值 key
                break;
            } else {
                $proSum -= $proCur;
            }
        }
        unset ($proArr);
        return $result;
    }
```



## 权重抽奖算法(推荐  20260803)

### 代码示例

```php
<?php

/**
 * 概率抽奖
 * @param array $prizeList [['id'=>1,'name'=>'一等奖','weight'=>5],...]
 * @return array 中奖奖品
 */
function lottery(array $prizeList): array
{
    $totalWeight = array_sum(array_column($prizeList, 'weight'));
    // 随机 1 ~ 总权重
    $rand = random_int(1, $totalWeight);

    $current = 0;
    foreach ($prizeList as $item) {
        $current += $item['weight'];
        echo $rand.':---:'.$current.PHP_EOL;
        if ($rand <= $current) {
            return $item;
        }
    }
    return end($prizeList);
}

// 奖品配置
$prizes = [
    ['id' => 1, 'name' => '一等奖', 'weight' => 1],
    ['id' => 2, 'name' => '二等奖', 'weight' => 10],
    ['id' => 3, 'name' => '三等奖', 'weight' => 50],
    ['id' => 4, 'name' => '谢谢参与', 'weight' => 939]
];

// 日志文件路径
$logFile = __DIR__ . '/lottery_log.txt';
$forCount=10000;
// 清空原有日志（如需追加删掉这句即可）
file_put_contents($logFile, "===== 抽奖{$forCount}次记录开始 时间：" . date('Y-m-d H:i:s') . " =====\n\n");

// 统计计数数组
$stat = [
    '一等奖' => 0,
    '二等奖' => 0,
    '三等奖' => 0,
    '谢谢参与' => 0,
];

// 循环1000次抽奖
for ($i = 1; $i <= $forCount; $i++) {
    $win = lottery($prizes);
    $name = $win['name'];
    $stat[$name]++;

    // 单行日志内容
    $logLine = "第{$i}次抽奖：中奖奖品 = {$name}\n";
    // 写入日志（追加）
    file_put_contents($logFile, $logLine, FILE_APPEND);
}

// 写入汇总统计
$summary = "\n===== 抽奖结束 总计{$forCount}次统计结果 =====\n";
foreach ($stat as $key => $val) {
    $summary .= "{$key}：{$val} 次\n";
}
$summary .= "结束时间：" . date('Y-m-d H:i:s') . "\n";
file_put_contents($logFile, $summary, FILE_APPEND);

echo "抽奖完成，共计{$forCount}次，日志已写入：" . $logFile;
```
