Qdrant = **向量数据库**。专门存向量、做**语义相似度搜索**，它就是 RAG 里的 “检索引擎”。

## 向量是什么

你把一段文字丢给 DeepSeek Embedding 接口，它会返回一长串浮点数数组（1024 个数字），这串数字就是**向量**。

意思是：把文字的语义，翻译成一串数字。

> 语义相近的文字 → 向量在空间里距离很近

比如：

- 文本 A：7 天无理由退款

- 文本 B：怎么申请退钱

  

  这两句话字面不一样，但是意思接近，它们的向量距离很近。

## 为什么不能直接用 MySQL？

MySQL 擅长：**关键词匹配**`where content like '%退款%'`

缺点：

1. 字面不一样，就搜不到（“退钱” 匹配不到 “退款”）
2. MySQL 没有内置向量相似度计算；你把向量存 json，只能 PHP 全部读出来循环算余弦相似度 → **数据一多直接卡死**

### docker安装

```php
docker run -d \
  -p 6333:6333 -p 6334:6334 \
  -e QDRANT__SERVICE__API_KEY="你的强密钥" \        # 例如   -e QDRANT__SERVICE__API_KEY="yaoliuyang"
  -v "$(pwd)/qdrant_storage:/qdrant/storage:z" \
  qdrant/qdrant
```

### docker-compose.yml 版本

```yaml
services:
  qdrant:
    image: qdrant/qdrant
    ports:
      - "6333:6333"
      - "6334:6334"
    environment:
      QDRANT__SERVICE__API_KEY: "你的强密钥"
      # 可选：只读密钥

    volumes:
      - ./qdrant_storage:/qdrant/storage
```

###  对应库的方法封装为service.php

`QdrantService.php`

```php
<?php

namespace App\Services;

use Illuminate\Support\Facades\Http;
use Qdrant\Config;
use Qdrant\Http\Builder;
use Qdrant\Qdrant;
use Qdrant\Models\Request\CreateCollection;
use Qdrant\Models\Request\VectorParams;
use Qdrant\Models\PointsStruct;
use Qdrant\Models\PointStruct;
use Qdrant\Models\VectorStruct;
use Qdrant\Models\Request\Points\QueryRequest;
use Qdrant\Models\Filter\Filter;
use Qdrant\Models\Filter\Condition\MatchString;

class QdrantService
{
    protected static ?self $instance = null;

    protected Qdrant $client;
    protected string $collection;

    /**
     * 私有化构造，禁止外部new
     */
    private function __construct()
    {
        // 拼接 Qdrant 服务地址：host + 端口号，例如 127.0.0.1:6333
        $host = config('qdrant.host') . ':' . config('qdrant.port');
        // 实例化 Qdrant 配置对象，传入服务连接地址
        $config = new Config($host);
        // 设置 Qdrant 访问密钥（对应后台 Access Tokens），无密钥可省略
        $config->setApiKey(config('qdrant.api_key'));
        // 构建底层传输通道，用于和 Qdrant 服务通信
        $transport = (new Builder())->build($config);
        // 实例化 Qdrant 客户端，后续所有增删改查、向量检索都通过这个 client
        $this->client = new Qdrant($transport);
        // 读取配置里的向量集合名称,rag_docs
        $this->collection = config('qdrant.collection');
    }

    /**
     * 获取单例
     */
    public static function getInstance(): self
    {
        if (is_null(self::$instance)) {
            self::$instance = new self();
        }
        return self::$instance;
    }

    // 禁止克隆
    private function __clone()
    {
    }

    /**
     * 创建Qdrant向量集合
     * 对应你面板里的 rag_docs 集合，向量维度1024，余弦相似度
     * @return void
     */
    public function createCollection(): void
    {
        // 实例化【创建集合】请求构造器
        $createCollection = new CreateCollection();
        // 添加向量参数配置
        // 第一个参数：VectorParams(向量维度, 距离算法)
        // 1024：embedding输出向量维度；DISTANCE_COSINE：余弦相似度，适合文本语义检索
        // 'default'：向量名称，默认向量字段名，检索时需要对应这个名称
        $createCollection->addVector(
            new VectorParams(1024, VectorParams::DISTANCE_COSINE),
            'default'
        );
        // 调用客户端，在指定集合名称下执行创建操作
        $this->client->collections($this->collection)->create($createCollection);
    }

    /**
     * 新增/更新向量点（upsert：存在则更新，不存在则新增）
     * @param string $pointId 向量点唯一ID（建议和业务文档片段ID保持一致）
     * @param array $vector 文本embedding之后得到的向量数组，长度必须是1024维
     * @param array $payload 附属元数据，比如原文、文档名称、分类、时间等自定义字段
     * @return void
     */
    public function upsertPoint(string $pointId, array $vector, array $payload): void
    {
        //如果集合不存在默认先创建集合
        if (!$this->collectionExists()) $this->createCollection();

        // 构造批量点结构对象，支持一次性写入多条Point
        $points = new PointsStruct();

        // 组装向量数据，'default' 对应创建集合时定义的向量名称
        $vectorStruct = new VectorStruct($vector, 'default');

        // 组装单条向量记录：PointStruct(点ID, 向量数据, 元数据payload)
        $points->addPoint(new PointStruct(
            $pointId,
            $vectorStruct,
            $payload
        ));

        // 执行upsert写入：如果pointId已存在就覆盖更新，不存在就新增
        $this->client->collections($this->collection)->points()->upsert($points);
    }

    /**
     * 按过滤条件删除（核心！更新文档用）
     * @param array $filter Qdrant filter 结构
     * @return void
     */
    public function deleteByFilter(array $filter): void
    {
        $this->client->collections($this->collection)
            ->points()
            ->delete([
                'filter' => $filter
            ]);
    }

    /**
     * 新版查询，使用 QueryRequest
     * @param array $vector
     * @param int $topN
     * @return array
     */
    public function search(array $vector, int $topN = 3): array
    {
        $queryRequest = (new QueryRequest())
            ->setQuery(['nearest' => $vector])
            ->setUsing('default')
            ->setLimit($topN)
            ->setWithPayload(true);

        $resp = $this->client->collections($this->collection)
            ->points()
            ->query()
            ->query($queryRequest);

        return $resp['result']['points'] ?? [];
    }

    public function dropCollection(): void
    {
        $this->client->collections($this->collection)->delete();
    }


    /**
     * 原生Http方式根据document_id删除向量点（保留旧实现）
     * @param string $documentId
     * @return void
     */
    public function deletePointsByDocumentIdHttp(string $documentId): void
    {
        try {
            $baseUrl = rtrim(config('qdrant.host') . ':' . config('qdrant.port'), '/');
            $url = "{$baseUrl}/collections/{$this->collection}/points/delete";

            $payload = [
                'filter' => [
                    'must' => [
                        [
                            'key' => 'document_id',
                            'match' => ['value' => $documentId]
                        ]
                    ]
                ]
            ];
            $headers = [];
            if (!empty(config('qdrant.api_key'))) {
                $headers['api-key'] = config('qdrant.api_key');
            }
            $resp = Http::withHeaders($headers)->post($url, $payload);
            if (!$resp->successful()) {
                throw new \Exception("Qdrant接口返回：" . $resp->body());
            }
        } catch (\Exception $exception) {
            throw new \Exception("Qdrant删除失败：" . $exception->getMessage());
        }
    }

    /**
     * 删除文档
     * @param string $documentId
     * @return void
     */
    public function deletePointsByDocumentId(string $documentId): void
    {
        try {
            $filter = (new Filter())->addMust(
                new MatchString('document_id', $documentId)
            );

            $this->client
                ->collections($this->collection)
                ->points()
                ->deleteByFilter($filter);

        } catch (\Throwable $exception) {
            throw new \RuntimeException(
                'Qdrant删除失败：' . $exception->getMessage(),
                previous: $exception
            );
        }
    }

    /**
     * 判断当前配置的集合是否存在
     * @return bool
     */
    public function collectionExists(): bool
    {
        try {
            // 尝试获取集合信息，成功=存在
            $res = $this->client->collections($this->collection)->exists();
            $bool = $res['result']['exists'] ?? false;
        } catch (\Exception $e) {
            return false;
        }
        return $bool;
    }
}

```





### 云端版本Qdrant Cloud 自带永久免费套餐（Free Tier），不用信用卡

**海外不推荐**

地址：https://cloud.qdrant.io

 免费版规格

- 单节点：0.5 vCPU，1GB 内存，4GB 磁盘
- 向量容量参考：大约 100 万条 768 维向量；**你用的 1024 维向量会更占内存，大概 50 万条左右**
- 支持 API Key、WebUI、多 Collection、过滤检索、upsert，和你现在本地 SDK 代码完全兼容，几乎不用改代码
- 自带免费内置 embedding 模型（all-MiniLM、BM25），可以直接在云端做向量化Qdrant

 重要限制（一定要看）

1. **闲置策略**：连续 7 天没访问 → 自动暂停；暂停后 4 周不激活 → 直接删除数据，适合开发调试，**不能放正式业务数据**Qdrant
2. 无高可用、无副本、没有 SLA 保障，区域选择少
3. 资源跑满（内存 / 磁盘超限）会变慢或者写入失败
4. 国内直连访问速度不稳定，偶尔超时（服务器在海外）
